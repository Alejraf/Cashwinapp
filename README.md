# Integración Mercado Pago Pix para RewardApp

## Pasos para configurar:
1. Entra a tu panel de desarrollador de Mercado Pago y obtén tu **Access Token de Producción** (comienza con `APP_USR-...`).
2. Configura tu variable de entorno `MERCADO_PAGO_ACCESS_TOKEN` en tu servidor.
3. Asegúrate de tener fondos en tu cuenta de Mercado Pago Brasil para cubrir los retiros de los usuarios.
